$ agentauth registry preset payments-usdc
USDC payments  (payments-usdc)
Lets an agent pay USDC to approved recipients with SPL Token transfer_checked and nothing else.
For: Teams letting an agent pay invoices, subscriptions or API fees in USDC.

Allows
  spl-token.transfer_checked  0c00000000000000, value_out

Risk
  The relay always enforces a recipient allowlist, and an empty allowlist refuses every transfer (relay error 104 RecipientNotAllowed). Worst case is the agent spending the lifetime limit to the allowlisted recipients, so list only token accounts you trust. Calls that bypass the relay are only advisory.

Not allowed (15, for example)
  spl-token.transfer  [not allowlisted, value_out] Moves tokens from an owner- or delegate-controlled account to a destination account chosen by the caller.
  spl-token.approve  [authority_change] Grants a delegate spending rights over the source account up to an amount, replacing any existing delegate.
  spl-token.revoke  [authority_change] Clears the account delegate and delegated amount; removes rather than grants authority.
  spl-token.set_authority  [authority_change] Reassigns or removes a mint authority, freeze authority, token-account owner or close authority.

Honest limits
  Per-tx limits are per verify call: AgentAuth checks each reported instruction against the limit independently, so N calls in one transaction or across transactions can each pass.
  Spend counters are unit-less per program: lifetime and per-tx amounts are plain numbers per program id, not per mint, so base units of different tokens (and lamports) are summed together. Choose limits in the units of one mint only.
  Only relay transfer_checked and the pinned swap are HARD enforced (the relay is the SPL delegate and checks recipient allowlist, budget and floor itself). Everything else in this preset is advisory unless the integrator calls AgentAuth verify before executing it.
  This preset does not stop the agent from sending to a wrong but allowlisted recipient, nor does it detect fraudulent invoices.

Use it: agentauth mandate create --preset payments-usdc --per-call <amount> --budget <amount> ...
[exit 0]
